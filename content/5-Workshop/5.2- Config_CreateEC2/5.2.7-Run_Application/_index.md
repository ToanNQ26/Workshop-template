## Overview

PM2 keeps the backend running after the SSH session closes and restores it after a reboot. Run PM2 commands as **ec2-user**, except for the startup installation command containing `sudo` generated by PM2.

## Procedure

### Step 1: Start the Application with PM2

```bash
cd comic-website
sudo -i
pm2 start ./src/server.js --name webtruyen_be
```

The process should be **online**, with no startup or database connection errors in the logs.

![Check the application process](/images/myimage/5_2_7/image1.png)

### Step 2: Enable Startup Persistence

```bash
pm2 startup
```

Run **the exact sudo command printed by PM2**, then:

```bash
pm2 save
```

The startup script depends on the user and Node.js path. Regenerate it if the Node.js version or installation changes.

### Step 3: Check the Application Process on EC2

Run:

```bash
pm2 status
```

If the application is running successfully, the output should resemble the screenshot below.

![Check PM2 status](/images/myimage/5_2_7/image2.png)

## Expected Outcomes

PM2 manages the backend, Nginx forwards API requests, and the process list has been saved.
